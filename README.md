### 💻 CÁCH KHỞI CHẠY VÀ TRIỂN KHAI:

#### 1. Chạy thử nghiệm cục bộ (Local Development):
```bash
npm run dev
```
Trang web sẽ chạy tại `http://localhost:5173/`.

#### 2. Đóng gói bản Production:
```bash
npm run build
```
Thư mục `dist/` đã sẵn sàng tối ưu hóa 100%.

#### 3. Triển khai lên Vercel:
```bash
vercel --prod
```
